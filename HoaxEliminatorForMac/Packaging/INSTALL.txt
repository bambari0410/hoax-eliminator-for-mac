Hoax Eliminator for Mac 설치 안내
==================================

은행이나 관공서 사이트에서 깔라고 했던 보안 프로그램을 찾아서 한 번에 정리하는 맥용 앱이에요.
원작자(BLUEnLIVE)가 만든 공식 맥 버전이 아니라, 윈도우용 구라제거기에서 아이디어를 얻은 별도 프로그램이에요.


필요한 것
---------
- macOS 13 이상
- Apple Silicon, Intel 맥 모두 쓸 수 있어요. (하나의 앱에 둘 다 들어 있어요)


설치
----
1. "Hoax Eliminator for Mac.app"을 응용 프로그램 폴더로 옮겨요.
2. 터미널을 열고 아래 명령을 붙여 넣은 뒤 return 키를 눌러요.

    xattr -dr com.apple.quarantine "/Applications/Hoax Eliminator for Mac.app"

3. 앱을 열어요.

이 앱은 Apple 공증을 받지 않은 테스트 빌드라서, 2번을 하지 않으면 처음 열 때
"열 수 없음" 경고가 나와요. 2번 명령은 인터넷에서 받은 파일에 붙는 격리 표시만 지워요.
GitHub 릴리스 페이지처럼 믿을 수 있는 곳에서 받은 파일에만 이렇게 해 주세요.


터미널 없이 여는 방법
--------------------
1. 앱을 열고, 경고 창에서 [완료]를 눌러요.
2. 시스템 설정 > 개인정보 보호 및 보안으로 가서, 아래쪽 보안 항목의
   "Hoax Eliminator for Mac"이(가) 차단되었습니다 옆의 [그래도 열기]를 눌러요.
3. 앱을 다시 열고, [그래도 열기]를 누른 뒤 맥 로그인 암호를 입력해요.

다음부터는 바로 열려요.


이렇게 동작해요
--------------
- 지운 파일은 바로 없애지 않고 휴지통으로 옮겨요. 잘못 지웠다면 휴지통에서 꺼내면 돼요.
- 공동인증서(NPKI) 폴더, 키체인의 다른 인증서, macOS 시스템 폴더는 건드리지 않아요.
- 맥 전체에 설치된 항목을 정리할 때는 관리자 암호를 한 번 물어봐요.
  그 전에 무엇을 실행하는지 모두 보여 드려요.
- 은행 사이트에 다시 들어가면 보안 프로그램을 설치하라고 할 수 있어요.
  그때 설치하고, 볼일을 마치면 다시 정리하면 돼요.


앱 삭제
-------
앱을 휴지통으로 옮기면 돼요.
설정(업무용 프로그램 표시 등)은 ~/Library/Preferences/local.HoaxEliminatorForMac.plist 에 남아요.
