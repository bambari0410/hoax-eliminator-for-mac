남은 흔적까지 꼼꼼하게

루트 인증서까지

키체인에 남은 업체 루트 인증서도 찾아서 함께 지워요. 이 인증서는 제작사 제거 프로그램으로 지워도 남는 경우가 많아요.

업무용은 남겨 둬요

숨은 프로그램도 찾아요

목록에 없는 프로그램도 이름으로 찾아볼 수 있어요. 정확하지 않을 수 있어서 처음에는 체크하지 않은 상태로 보여 줘요.

인터넷 없이, 무료로

윈도우 구라제거기와 무엇이 다른가요?

윈도우용 구라제거기는 맥에서 실행되지 않아요. 맥에는 '프로그램 추가/제거' 목록도 없어서, 찾는 방법부터 달라요.

윈도우용 구라제거기 Windows

  • '프로그램 추가/제거' 목록에서 보안 프로그램을 찾아요.
  • 제작사가 넣어 둔 제거 프로그램을 차례로 실행해요.
  • ActiveX나 키보드 보안 드라이버처럼 윈도우에만 있는 것도 다뤄요.

Hoax Eliminator for Mac macOS

  • 설치하면서 남긴 흔적을 하나하나 직접 찾아요.
  • 로그인할 때마다 뒤에서 도는 자동 실행 설정을 정리해요.
  • 키체인에 남은 업체 루트 인증서까지 챙겨요.

지울 때도 안전하게

지우는 프로그램일수록 조심해야 해요. 그래서 되돌릴 수 있는 방법을 먼저 골랐어요.

휴지통으로만 옮겨요

파일은 바로 지우지 않고 휴지통으로 옮겨요. 잘못 지웠다면 휴지통에서 꺼내면 돼요.

손대지 않는 곳이 있어요

공동인증서(NPKI) 폴더, 키체인의 다른 인증서, macOS 시스템 폴더는 건드리지 않아요.

같이 쓰는 폴더는 마지막에

여러 회사 프로그램이 함께 쓰는 폴더는 안이 비어 있을 때만 정리해요.

실행 전에 모두 보여 드려요

관리자 암호가 필요한 작업은 무엇을 실행하는지 먼저 보여 드려요. 암호 창에서 취소하면 아무것도 바뀌지 않아요.

자주 묻는 질문

정말 무료인가요?

네, 무료예요. MIT 라이선스로 공개한 오픈소스라서 누구나 쓸 수 있고, GitHub에서 코드도 볼 수 있어요.

맥에서도 구라제거기를 쓸 수 있나요?

윈도우용 구라제거기는 맥에서 실행되지 않아요. Hoax Eliminator for Mac은 구라제거기에서 아이디어와 화면 구성을 얻어 맥용으로 따로 만든 무료 프로그램이에요. 원작자(BLUEnLIVE)와 관계없는 별도 프로그램이고, 공식 맥 버전은 아니에요.

처음 열 때 "열 수 없음" 경고가 나와요.

아직 Apple 공증을 받지 않아서 그래요. 경고 창에서 [완료]를 누르고, 시스템 설정 > 개인정보 보호 및 보안에서 [그래도 열기]를 눌러요. 앱을 다시 열고 [그래도 열기]를 누른 뒤 맥 로그인 암호를 입력하면 돼요. 다음부터는 바로 열려요.

지우고 나면 은행 사이트를 못 쓰나요?

사이트에 다시 들어가면 보안 프로그램을 설치하라고 안내해요. 그때 설치해서 쓰고, 볼일을 마치면 다시 정리하면 돼요.

관리자 암호는 왜 물어보나요?

맥 전체에 설치된 항목은 관리자 권한이 있어야 옮길 수 있어요. 암호를 묻기 전에 실행할 명령을 모두 보여 드리고, 암호 창에서 취소하면 아무것도 바뀌지 않아요.

공동인증서도 지워지나요?

아니요. 공동인증서(NPKI) 폴더와 키체인의 다른 인증서는 건드리지 않아요. 지우는 인증서는 보안 프로그램 업체가 설치하면서 넣어 둔 루트 인증서뿐이에요.

잘못 지웠어요. 되돌릴 수 있나요?

파일은 휴지통으로 옮기기 때문에 휴지통에서 꺼내면 돼요. 업체 루트 인증서와 설치 기록은 휴지통에 들어가지 않지만, 보안 프로그램을 다시 설치하면 다시 생겨요.

회사 업무에 꼭 필요한 프로그램이 있어요.

[업무용 프로그램 관리…]에서 표시해 두세요. '업무용 프로그램은 지우지 않기'를 켜 두면 체크가 빠지고, [모두 제거]를 눌러도 남겨 둬요.

인터넷에 연결해야 하나요? 내 정보가 어디로 가나요?

인터넷을 쓰지 않아요. 맥 안에서만 찾고 정리하고, 어디로도 아무것도 보내지 않아요.

지금 바로 정리해 보세요

macOS 13 이상, Apple Silicon과 Intel 맥 모두에서 쓸 수 있어요. zip 파일을 풀고 앱을 응용 프로그램 폴더로 옮기면 돼요.

다운로드 v0.1 (zip, 1.1MB) 체크섬 파일
shasum -a 256 -c Hoax-Eliminator-for-Mac-0.1.zip.sha256

받은 파일과 체크섬 파일을 같은 폴더에 두고 터미널에서 실행해서 "OK"가 나오면 돼요.

처음 열 때 "열 수 없음" 경고가 나오면

  1. 경고 창에서 [완료]를 눌러요.
  2. 시스템 설정 > 개인정보 보호 및 보안에서 [그래도 열기]를 눌러요.
  3. 앱을 다시 열고 [그래도 열기]를 누른 뒤 맥 로그인 암호를 입력해요.
